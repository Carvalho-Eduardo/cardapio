
# 🍔 Cardápio Online

Aplicação web de cardápio digital desenvolvida para apresentar produtos de um estabelecimento de forma organizada, moderna e acessível.

O projeto tem como objetivo facilitar a visualização dos produtos pelos clientes e demonstrar, na prática, conhecimentos de desenvolvimento web.

## 📌 Sobre o projeto

O Cardápio Online é um projeto que explora a criação de uma interface digital para exibição de produtos.

A proposta é oferecer uma experiência simples e intuitiva, permitindo que os usuários visualizem as opções disponíveis por meio de uma página web.

## ✨ Objetivos e funcionalidades

- 🍔 Apresentação visual dos produtos.
- 📱 Interface adaptável a diferentes tamanhos de tela, conforme implementado.
- 🧭 Navegação simples e intuitiva.
- 🎨 Organização visual das informações do cardápio.
- 🌐 Acesso por navegador.

## 🛠️ Tecnologias

Confira o código e o arquivo `package.json` para confirmar a stack exata deste repositório.

O projeto de cardápio que desenvolvi utiliza ferramentas do ecossistema web, incluindo as seguintes tecnologias, conforme aplicáveis à versão deste repositório:

- **React** — construção de interfaces.
- **Vite** — ambiente de desenvolvimento e build.
- **JavaScript** — lógica da aplicação.
- **Tailwind CSS** — estilização da interface.
- **Lucide React** — ícones da interface.
- **Vercel** — hospedagem da versão online, se vinculada a este repositório.

## 🎯 Objetivos de aprendizado

- Praticar o desenvolvimento de interfaces web.
- Organizar componentes e estilos.
- Construir uma experiência de navegação intuitiva.
- Aplicar conceitos de responsividade.
- Conhecer o fluxo de publicação de um projeto web.
